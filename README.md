# Python Grade Generator

A Python-based grade calculator and management system designed for academic grading with support for Formative Assessment (FA) and Summative Assessment (SA) categories. The system calculates weighted grades, GPA, and pass/fail status based on customizable assignment weights.

## Features

- **Interactive Grade Entry**: User-friendly prompts for entering assignment details
- **Dual Assessment Categories**: Support for Formative (FA) and Summative (SA) assessments
- **Weighted Grade Calculation**: Automatically calculates weighted scores based on assignment weights
- **GPA Conversion**: Converts final grades to a 5.0 GPA scale
- **Pass/Fail Logic**: Determines pass/fail status requiring ≥50% in both FA and SA categories
- **CSV Export**: Saves all assignment data to a CSV file for record-keeping
- **Automated Archiving**: Shell scripts to archive old grade files with timestamps

## Requirements

- Python 3.x
- No external dependencies (uses standard library only)

## Usage

### Running the Grade Generator

Execute the main script:

```bash
python grade-generator.py
```

### Input Process

The program will prompt you for each assignment:

1. **Assignment Name**: Enter a descriptive name
2. **Category**: Choose FA (Formative) or SA (Summative)
3. **Grade**: Enter the score obtained (0-100)
4. **Weight**: Enter the assignment weight (positive number)

After each assignment, you'll be asked if you want to add another. Enter 'y' to continue or 'n' to finish.

### Example Session

```
Grade Generator - enter assignment details. Press Enter when prompted.

Enter assignment details:
  Assignment name: Quiz 1
  Category (FA/SA): FA
  Grade obtained (0-100): 85
  Weight (positive number, e.g., 30): 10
Add another assignment? (y/n): y

Enter assignment details:
  Assignment name: Final Exam
  Category (FA/SA): SA
  Grade obtained (0-100): 92
  Weight (positive number, e.g., 30): 50
Add another assignment? (y/n): n
```

### Output

The program generates:

1. **Console Summary**: Detailed grade breakdown showing:
   - Individual assignments with weighted scores
   - Category totals (FA and SA)
   - Final grade out of 100
   - GPA on a 5.0 scale
   - Pass/fail status for each category
   - Overall pass/fail result

2. **CSV File** (`grades.csv`): Saved assignments with columns:
   - Assignment name
   - Category
   - Grade
   - Weight

## Grade Calculation

### Weighted Score
For each assignment:
```
Weighted Score = (Grade / 100) × Weight
```

### Final Grade
```
Final Grade = Sum of all Weighted Scores
```

### GPA
```
GPA = (Final Grade / 100) × 5.0
```

### Pass/Fail Criteria
- Must achieve ≥50% of the total weight in FA category
- Must achieve ≥50% of the total weight in SA category
- Both conditions must be met for an overall PASS

## Archiving System

The project includes two archiving scripts to manage old grade files:

### PowerShell (Windows)
```powershell
.\organizer.ps1
```

### Bash (Linux/Mac)
```bash
./organizer.sh
```

### What the Archiving Scripts Do:
- Move all CSV files from the current directory to an `archive` folder
- Rename files with timestamps (format: `YYYYMMDD-HHMMSS`)
- Log all archiving actions to `organizer.log` including file contents
- Prevent overwrites with random suffixes if needed

## Input Validation

The program includes robust input validation:
- **Non-empty inputs**: All fields require valid input
- **Category validation**: Only accepts 'FA' or 'SA' (case-insensitive)
- **Numeric validation**: Ensures grades and weights are valid numbers
- **Range checking**: Grades must be 0-100, weights must be positive
- **Error handling**: Clear error messages guide users to correct input
